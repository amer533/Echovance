Validation rules

  • Required columns: tweet_id, author_id, inbound, created_at, text; optional response_tweet_id, in_response_to_tweet_id.
  • Dates must include a timezone (Twitter format or ISO 8601). Future dates are rejected.
  • Outbound rows must come from the brand account; they are stored as agent replies and never analysed as complaints.
  • Only customer thread roots (no in_response_to_tweet_id) become complaint candidates.
  • E-mail addresses and long digit sequences are redacted before storage. Row errors list row number, field and code only.
  • Limits: {{ max_upload|filesizeformat }} and {{ max_rows|intcomma }} rows per file. Larger raw dumps go through scripts/prepare_dataset.py and manage.py import_messages.
